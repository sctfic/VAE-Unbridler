# ESP32 V1 1.0.7 — test de mise à jour OTA

Version de test identique en fonctionnement à la 1.0.6.
Seuls la version firmware (1.0.7) et le code OTA (6) augmentent pour permettre
une nouvelle installation depuis la 1.0.6.

Utiliser Android 0.4.28 pour tester le transfert rapide, la progression et le
redémarrage. Le GPS ne bloque pas l'installation ; seul un mouvement du capteur
de roue d'origine intervient dans ce contrôle. Les trois impulsions anti-veille
et le clignotement orange/violet restent identiques.

Le binaire et son manifeste sont préparés et vérifiés avant publication.
