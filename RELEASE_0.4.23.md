# Version 0.4.23

- Setting : MAC, nom modifiable et version du firmware sur une ligne, sans statut de connexion.
- Saisie du périmètre ou du diamètre avec le bouton de changement de mode à droite.
- Circonférence calculée visible uniquement en mode diamètre.

- OTA pour le matériel V1.0 : deux partitions alternées, téléchargement GitHub,
  nom du VAE clignotant et installation au toucher sous condition d’immobilité.
- Progression détaillée, contrôle SHA-256 sur téléphone et ESP32, confirmation
  du nouveau démarrage et retour à l’image précédente si elle reste sans validation.
- Les diagnostics BLE, le nom personnalisé et l’affichage de la version firmware
  sont conservés. Firmware V1.0 : 1.0.2 ; première installation complète par USB.
