# Ancienne description des événements BLE v2

Ce format a été supprimé du projet. Le firmware 1.0.6 et l'application 0.4.28
utilisent exclusivement le format compact décrit dans [BLE_PROTOCOL.md](BLE_PROTOCOL.md).
Les séquences, horodatages, confirmation Turbo et lissage restent présents ;
la fragmentation et les compteurs de diagnostic sont retirés.
